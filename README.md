# 🧠 Trivia Quiz Game

משחק טריוויה אינטראקטיבי ומעוצב המבוסס על דפדפן. המשחק מאפשר למשתמשים לבחון את הידע שלהם במגוון נושאים עם ממשק משתמש נקי וחוויית משחק זורמת.

---

## 🚀 תכונות עיקריות (Features)

* **שאלות רב-ברירה:** מבנה שאלות אמריקאיות קלאסי.
* **עיצוב רספונסיבי:** מותאם לעבודה במחשב ובמכשירים ניידים.
* **ממשק דינמי:** מעבר חלק בין שאלות ועדכון תוצאה בזמן אמת.
* **משוב מיידי:** המשתמש מקבל אינדיקציה אם צדק או טעה מיד לאחר הבחירה.
* **סיכום תוצאות:** בסוף המשחק מוצג הניקוד הסופי עם אפשרות למשחק חוזר.

---

## 🛠 טכנולוגיות (Tech Stack)

הפרויקט נבנה באמצעות טכנולוגיות ה-Web הבסיסיות והיציבות ביותר:

* **HTML5:** למבנה הסמנטי של המשחק.
* **CSS3:** לעיצוב, אנימציות וחוויית משתמש (UI/UX).
* **JavaScript (ES6+):** לניהול הלוגיקה של המשחק, השאלות והניקוד.

---

## ⚙️ איך להריץ את הפרויקט?

אין צורך בהתקנות מורכבות או בשרת backend. פשוט עקבו אחרי הצעדים הבאים:

1.  **שכפול המאגר (Clone):**
    ```bash
    git clone [https://github.com/ELIAV123456/Trivia-quiz.git](https://github.com/ELIAV123456/Trivia-quiz.git)
    ```
2.  **כניסה לתיקייה:**
    ```bash
    cd Trivia-quiz
    ```
3.  **הפעלת המשחק:**
    פשוט פתחו את הקובץ `index.html` בכל דפדפן מודרני (Chrome, Edge, Firefox).

---

## 📂 מבנה הפרויקט

* `index.html` - הקובץ הראשי שמכיל את מבנה המשחק.
* `style.css` - עיצוב המשחק, הצבעים והפריסה (Layout).
* `script.js` - הלוגיקה של המשחק: טעינת שאלות, בדיקת תשובות וניהול מצב המשחק.
